## Project 2

This is a continuation of Project 1.

I would strongly recommend starting from a fresh new repo for this project.

Because we've learned so many new things that will likely change your layout, it may be easier to start over than attempt to adapt what you previously had. Personally, I find it helpful to only copy over bits and pieces from a previous project, but you can do whatever you would like. You are also allowed to pivot your project idea if you would like to, I want this project to be something you are passionate about and will live beyond the scope of this class.

- There are no requirements for the number of pages you have for this project. Especially with flexbox and grid, single page layouts can look very clean and nice
- Use semantic HTML elements for document structure
- All elements should be styled with CSS. Do not leave any default HTML styling
- Use flexbox, grid, and media queries to make your website fully responsive
- Include your own on load or background animation
- Follow basic HTML and CSS accessibility principles (img alt, WCAG colors, rem, prefers-reduced-motion)
- Run your project through Google Lighthouse to catch any accessibility errors

As a reminder, these requirements are just a starting point. Meeting these requirements alone will not get you 100%. I want you to go above and beyond, impress me with your HTML and CSS skills. Be creative and have fun with this project! Don't be afraid to try new things.

In your `README.md`, include a brief description of your project and what you learned while building it. I would love to hear about your initial ideas for approaching Project 2, problems you ran into, and how your project evolved. Give descriptions for design and layout decisions that you made.
