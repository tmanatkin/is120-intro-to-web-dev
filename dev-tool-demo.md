## Dev Tool Demo

Dev Tool Demo Day is on March 9th.

Sign up here. Please sign up for two tools. https://docs.google.com/spreadsheets/d/1QhvYeQPp2Q5JlBYPV09UeoOAFojmHzKVRIdvXGbMNps/edit?usp=sharing

These are developer tools that will help you with design, colors, icons, images and more as you continue to build websites.

These tools vary a lot in complexity, so don’t just grab the easiest two when you sign up. Try to pick at least one that challenges you a bit.

If you have your own tool you’ve found that you want to add, feel free to do that as well!

For each tool, you will show:

- How it works: walk everyone through the features and options. Some are fairly extensive, so spend some time learning and using them before you demo.
- How you used it: show real examples from your own code where you used this tool.

No slides needed, this is a casual demo where you’re just showing the class how to use some tools effectively.

Plan on your demo for both tools taking 5-10 minutes total.
