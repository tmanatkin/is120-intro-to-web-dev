## JavaScript Weather Forecast

Create a GitHub repo for this assignment named `is120-hw10-firstname-lastname`.

Build a dynamic weather forecast using JavaScript conditionals and loops. Here are some instructions on what I want you to build.

- You will start with an array of numbers representing estimated temperatures for the next 5 days. Start with hardcoded numbers.
- Temperatures will be displayed in 5 separate card elements, each showing its date and temperature. These cards should be dynamically generated based on the length of the temperature array, not hardcoded in HTML.
- Each card will also need to display a weather category (e.g., Cold, Mild, Hot) based on the temperature value. You will also need to change the background color of the card based on its weather category.
- After you get everything working properly, replace your hardcoded temperature values with randomly generated numbers. Loops should be very helpful here to populate this array. We haven't covered generating random numbers in class, so feel free to use AI or other internet resources to help you figure out how to do this. Use 0-100 degrees for the range of your random temperatures.
- Include an external CSS file with minimal styling to make your weather forecast look presentable.

In your `README.md` include the following:

- What specific loops did you use in this assignment and why?
- Why do you think it's important that your cards are generated dynamically based on the array length instead of hardcoded in HTML? How would you add a 6th or 7th day to your forecast?
- What was the most difficult problem of this assignment and how did you work through it?

Publish using GitHub pages and include the live URL in your repo about section. Submit the GitHub repo URL in LearningSuite.
